# 将棋NEXT — ローグライト将棋 設計書

作成日: 2026-07-19 / ステータス: 承認済み設計(実装計画はこの後 writing-plans で作成)

## 1. コンセプト

[将棋ライク](https://unityroom.com/games/shougi-like)にインスパイアされたローグライト将棋。
通常の将棋(9x9固定盤・初期配置40枚)をベースに、特殊能力を持つ追加駒を獲得しながら全15面を勝ち進み、最終ボスの撃破を目指す。ブラウザで動作する。

将棋ライクとの意図的な差分:

- 盤面は常に9x9固定(将棋ライクは可変)
- HP/攻撃力制ではなく**純粋な将棋ルール**(利きに入った駒は即取り)
- 持ち駒ルールあり(通常駒のみ)

## 2. 確定済みの意思決定

| 項目 | 決定 |
|---|---|
| プラットフォーム | ブラウザゲーム。Vite + TypeScript(strict)、ランタイム依存ゼロ |
| 戦闘ルール | 純粋な将棋ルール(即取り)。HP等はなし |
| 持ち駒 | 通常駒(歩香桂銀金角飛)のみ持ち駒化・打ち可。特殊駒は取られたら消滅(例外は駒個別に明記) |
| 編成 | 各面開始前の編成画面で、獲得済み特殊駒を初期配置の通常駒(玉以外)と入れ替え |
| 駒獲得 | 各面クリア後、ランダム3枚から1枚選択(スキップ可) |
| 敗北 | 完全ロスト。獲得駒を全て失い1面から再スタート |
| 初心者モード | ラン開始時に神話レア1枚+天上レア1枚を獲得・編成済みで開始する救済モード(§4.1.1) |
| レアリティ | コモン/アンコモン/レア/神話レア/天上レア/禁忌レア/超越レアの7段階。超越レアは将棋の前提そのものを壊す最上位 |
| 敵編成 | 敵も面進行に応じ特殊駒を編成。5/10/15面はプレイヤー入手不可の専用ボス駒を持つボス |
| 勝利条件 | 王(またはボス駒)を実際に取るか、天下人が5五で自分の手番終了を3回迎えたら勝ち。王手放置も合法 |
| アーキテクチャ | 素のTS+DOM盤。コアは純粋関数、能力はデータ+フック、AIはWeb Workerでミニマックス |

## 3. ゲームルール詳細

### 3.1 基本

- 盤は9x9。両軍とも通常将棋の初期配置(40枚)を基本とし、編成画面での入れ替えのみ配置が変わる。
- 手番はプレイヤー先手。交互に1手ずつ。
- 勝敗条件: 相手の**ロイヤル駒**(王・太子・ボス駒)を全て取ったら勝ち。自分のロイヤル駒を全て取られたら負け。両軍対称のルール(敵の酔象が太子に成った場合も同様)。
- 追加勝利条件: 自軍の天下人が5五で自分の手番終了を3回迎えた場合も即勝利する。
- 用語: 「隣接」=周囲8マス。「自陣」=自分側の1〜3段目。
- **王手放置・自殺手も合法**。詰み判定は行わない(58種の特殊駒・ボスとの組み合わせバグを構造的に排除するため)。王手中はUIに警告を表示する。
- 千日手・持将棋の判定はしない。AIの千日手ループは評価関数の微小乱数と進行ボーナスで回避する。

### 3.2 持ち駒と打ち

- 取った**通常駒**は持ち駒になり、通常将棋と同じく空きマスに打てる(成り駒を取ったら元の駒として持つ)。
- 二歩は禁止。行き所のない打ち(最奥段の歩香、最奥2段の桂)は禁止。
- 打ち歩詰めは判定しない(詰み概念がないため。王を取られる側が回避できなければそのまま負け)。
- 取った**特殊駒**は持ち駒にならず消滅する(妖狐など駒個別の例外を除く)。
- エンジンが盤上へ生成・複製・蘇生した駒は**顕現駒**となる。顕現駒は通常駒でも捕獲時に相手の持ち駒にならず墓地へ消滅する。通常の打ちと産土神の自動配置は顕現ではない。

### 3.3 成り

- 通常将棋準拠: 敵陣3段目に「入る/出る/中で動く」移動の後に成りを選択できる(不成も可)。
- 行き所のなくなる移動は強制成り(歩香桂のルールを特殊駒にも一般化。該当駒は全て成り先を持つよう設計済み)。
- 成り先の記載がない特殊駒は成れない。
- **特殊駒は成っても固有能力を保持する**(動きだけが変わる)。例外: 酔象→太子のように成り自体が能力になっているもの。

## 4. ラン構造

### 4.1 フロー

```
タイトル ─→ モード選択(通常 / 初心者) ─→ ラン開始
             └→ [編成画面 → 対局 → 勝利 → 報酬3択] × 15面 → 15面クリアでラン勝利
敗北 → リザルト(到達面・獲得駒表示) → 全ロスト → タイトルへ
```

### 4.1.1 初心者モード(初心者救済)

- 新規ラン開始時にモードを選ぶ。**初心者モード**では、神話レアと天上レアからそれぞれ等確率で選んだ特殊駒を1枚ずつ、計2枚を**獲得済み+編成済み**の状態でランを開始する。
- 初期セット位置は§5の置換規則に従い、互いに異なる金角飛系の初期マスへ自動配置する。1面開始前の編成画面で自由に変更できる。
- それ以外のルール(報酬・敵編成・完全ロスト)は通常モードと同一。リザルトと統計にはモードを記録する。

### 4.2 編成ルール

- 獲得済み特殊駒は「控え」として無制限に所持できる。同一駒の複数所持も可。
- 編成画面で、初期配置の通常駒(玉以外の39枚)と特殊駒をクリックで入れ替える。特殊駒は入れ替えた通常駒の初期位置に置かれる。
- 特殊駒を控えに戻して通常駒に戻すのも自由。編成は面をまたいで記憶される。

### 4.3 報酬抽選

クリアした面に応じたレアリティ確率で、互いに異なる3枚を提示(所持済みの駒も提示され得る)。

| クリア面 | コモン | アンコモン | レア | 神話レア | 天上レア | 禁忌レア | 超越レア |
|---|---:|---:|---:|---:|---:|---:|---:|
| 1〜3 | 1% | 14% | 45% | 35% | 5% | 0% | 0% |
| 4(通常面) | 1% | 9% | 40% | 40% | 10% | 0% | 0% |
| **5(ボス)** | 0% | 0% | 27% | 45% | 20% | **5%** | **3%** |
| 6〜9 | 1% | 7% | 32% | 45% | 15% | 0% | 0% |
| **10(ボス)** | 0% | 0% | 16% | 45% | 28% | **7%** | **4%** |
| 11〜12 | 1% | 4% | 23% | 42% | 24% | **4%** | **2%** |
| 13〜14 | 0% | 3% | 13% | 41% | 32% | **8%** | **3%** |
| 15 | ランクリアのため報酬なし | | | | | |

コモンは全区間で最大1%とする。禁忌レアは1〜4面および6〜9面では出現せず、ボス撃破後と終盤にのみ4〜8%で出現する。

### 4.4 永続化

- ランの状態(現在面・所持駒・編成・対局中の盤面と手番)を**1手ごと**にlocalStorageへ自動保存。リロードで途中から再開。敗北直前リロードによる巻き戻しはさせない(敗北確定時に即セーブ)。
- 図鑑(遭遇/獲得済み駒)・統計(クリア回数、最高到達面)は別キーで永続。
- キー: `syoginext:run` / `syoginext:codex` / `syoginext:stats`。全て`version`フィールドを持つJSON。

## 7. 能力の裁定(エッジケース)

1. **取られない系(土竜・盾兵・軍神オーラ・覇王オーラ)**: 該当する捕獲手はそもそも合法手として生成されない。王の捕獲だけは全ての保護を無視できない=王・太子・ボス駒は保護対象外(§6.4 M4のとおり)ため、「王が取れない」手詰まりは発生しない。
2. **道連れ・爆発と王**: 王・太子・ボス駒はいかなる能力でも消滅しない(取られる時は通常の捕獲のみ)。
3. **爆弾兵の連鎖**: 爆発で別の爆弾兵が消滅した場合、その爆発も連鎖する。爆発で怨念が消えても道連れは発動しない(「取られた」ではないため)。
4. **不死鳥・妖狐 vs 道連れ等**: 「取られた」扱いの能力は捕獲時のみ発動。爆発・狙撃による消滅では発動しない。
5. **ボスの回避ワープ**: プレイヤー手番の完全終了後(能力処理含む)に判定。ワープは1手番につき最大1回消費。
6. **獅子の2段動作**: 1回目の移動で王を取ったら即勝利(2回目は行わない)。獅子が1手で2枚取ることも可。
7. **成りと能力**: 特殊駒は成っても固有能力を保持(§3.3)。金成りした怨念は存在しない(怨念は成れない)ように、成り不可駒は敵陣でもそのまま。
8. **強制成り**: その移動後に動けなくなる駒は強制成り。該当: 石将・鉄将・兎・弓兵(+通常の歩香桂)。
9. **AIと能力**: アクティブ能力(隠密・影武者・狙撃手・傀儡師・磁将・石化)も合法手として生成し、AIも使用する。
10. **石化の裁定**: 石化中の駒は移動・捕獲・能力使用が一切できない(利きなし扱い。王手警告やボスの回避ワープ判定にも数えない)。効果は相手の次の手番終了まで。
11. **報酬抽選の手順**: 3枠それぞれ独立に§4.3の確率でレアリティを抽選し、そのレアリティの駒から未選出のものを等確率で選ぶ(3枚は互いに異なる駒になる)。
12. **消滅系能力**: 落雷・十拳剣・断罪・捕食・死神の範囲消滅は捕獲ではない。怨念・妖狐・不死鳥・爆弾兵などの捕獲時効果は発動せず、持ち駒にもならない。
13. **自動行動順**: 手番側の移動解決後、自動行動フェーズ開始時に盤上にいる手番側の自動行動駒を盤面マス昇順でスナップショットして処理し、その後に石化解除、ボス回避、手番交代を行う。フェーズ中に生成された分身は次回から処理する。生成先・対象はシード付きRNGで決め、候補なしでもカウントは進む。
14. **自動捕食と守護**: 八岐大蛇の捕食は通常の捕獲保護判定を通す。軍神・覇王オーラや土竜・盾兵の保護対象は捕食できない。
15. **残影**: 通常移動の全段階が終わり本人が生存している場合、最初の移動元にだけ歩を生成する。アクティブ能力による移動では生成しない。
16. **刻停と麻痺**: 刻停は敵全非ロイヤルへ石化1手番を付与する。天照に隣接する敵非ロイヤルは利きも能力も持たない。ロイヤルは両方に免疫。
17. **月読の打ち封印**: 敵の月読が1体でも盤上にいる間、持ち駒を打つ合法手は生成されない。通常移動・能力は使用できる。
18. **龍神の貫通**: 各スライド方向で敵味方を問わず1枚だけ飛び越えられる。飛び越えた駒は取らず、敵駒上へ着地した場合だけ通常捕獲になる。2枚目より先へは進めない。
19. **合法手ゼロのパス**: 合法手がない側は自動的にパスする。パスでも自動行動、石化解除、ボス回避、手番交代を通常どおり処理する。
20. **生成駒**: エンジンが生成・複製・蘇生した駒は顕現駒となり、通常駒でも捕獲時に持ち駒にならない。盤上生成には二歩制約を適用しない。通常の打ちと産土神の自動配置は顕現ではない。
21. **墓地**: 盤上から持ち駒にならず除去された非ロイヤル駒を、除去順に`defId`と成り状態で記録する。通常駒の捕獲、妖狐の歩返還、復活に成功した不死鳥は記録しない。
22. **冥府の門**: 墓地の先頭を、門の持ち主・元の成り状態で隣接空きマスへ蘇生する。空きがなければ墓地を消費しない。能力回数と自動行動カウントは初期化する。
23. **魔王の捕食**: 守護判定を通る隣接敵非ロイヤルを優先する。敵候補がなければ自身を除く隣接味方非ロイヤルを捕食する。いずれも墓地へ送る。
24. **下剋上**: 通常移動解決後に相手側最奥段へ到達していれば、敵非ロイヤルを全て墓地へ送る。ロイヤルと味方は残る。成り先を持たないため強制成りの例外とする。
25. **契約と呪い**: 呪いがない間、自軍の契約の魔神が盤上にいれば王だけを8方向2マスへ強化する。魔神が理由を問わず盤上から除去されると、その側の王は対局終了まで前1だけになる。太子は影響を受けない。
26. **血の女王の供物**: 捕獲時点で持ち駒があれば追撃を選べる。追撃直前に歩→香→桂→銀→金→角→飛の順で最安の1枚を消費する。供物がなくなっていれば追撃は行わない。
27. **星喰いの終焉**: 王・太子・ボス以外の盤上全駒を墓地へ送り、両軍の持ち駒を空にする。星喰い自身と冥府の門も消滅する。持ち駒は墓地へ入れない。
28. **天邪鬼の交換**: 捕獲でも移動でもないため捕獲時効果・成り判定は発生しない。所有者、成り、能力回数、自動カウントを保ったまま位置だけを交換する。
29. **既存能力との関係**: 墓地は記録先を追加するだけで、道連れ・爆発連鎖・妖狐・不死鳥など既存効果の発動条件を変更しない。
30. **セーブ互換**: 旧対局セーブに墓地または王の呪いがなければ、空の墓地と両軍未呪いをロード時に補完する。
31. **顕現駒**: 自動生成・複製・残影・冥府の蘇生で作られた駒は捕獲されても持ち駒にならず墓地へ行く。寝返っても顕現属性は維持する。
32. **神罰**: 任意の敵非ロイヤルを指定し、そのマスと周囲8マスの非ロイヤルを敵味方無差別に墓地へ送る。捕獲時効果と爆弾の誘爆は発動しない。
33. **完全防護**: 不動明王に隣接する同陣営の非ロイヤルは捕獲・消滅・押し出し・引き寄せ・石化・交換・捕食・寝返りの対象にならない。不動明王自身とロイヤルは対象外。
34. **強奪**: プレイヤー側の酒呑童子が特殊駒を捕獲すると基礎駒IDを記録し、対局勝利時に控えへ加える。敵側の強奪は記録しない。
35. **修羅の連撃**: 最初の捕獲後に1回追加行動でき、その追加行動も捕獲ならさらに1回行動できる。途中で道連れ・爆発により修羅が消えた場合は残りを行わない。
36. **産土神の自動配置**: 全持ち駒から等確率で1枚を選び、自陣の合法な打ち先へ通常駒として配置する。二歩・行き所・月読の封印を守り、候補がなければ不発。
37. **絡新婦の引きずり**: 8方向の各直線で最初に見つかった敵非ロイヤルのうち、2マス以上離れ、防護されていない候補を1体選び隣へ移動する。捕獲と成りは発生しない。
38. **常世神の無限機関**: 自軍の常世神が盤上にいる間、残回数0でもアクティブ能力を使用でき、使用時に残回数を減らさない。常世神を失うと元の残回数管理へ戻る。
39. **禁忌第2弾のセーブ互換**: `stolen`や`conjured`がない旧セーブは空配列・未指定として安全にロードする。
40. **輪廻のループ移動**: 縦横の端を越えると反対端へ続き、最大8歩で打ち切る。途中の遮蔽と捕獲停止は通常スライダーと同じ。
41. **天下人の玉座**: 持ち主の自動行動と相手の後の先を解決した後、5五にいればカウントを増やし、いなければ0へ戻す。3で勝利。
42. **写し身の習得**: 捕獲した基礎`defId`の動きだけを重複なしで合成する。能力・フックは習得せず、写し身を失えば習得も失う。
43. **波動球**: 指定方向の敵非ロイヤルを遠い順に、盤端または別駒の手前まで押す。味方・ロイヤル・完全防護駒は動かず壁になる。
44. **後の先**: 手番側の自動行動後、非手番側の後の先をマス昇順で処理する。最高価値の敵非ロイヤルを通常捕獲し、石化・麻痺中は不発。
45. **軍師の連携**: 軍師の移動後、隣接味方非ロイヤルの合法な1歩を任意で行う。捕獲は通常処理し、成りと移動時フックは発動しない。
46. **天地返し**: `newBoard[i]=oldBoard[80-i]`で盤全体を反転する。所有権・成り・能力回数・状態を保ち、移動や捕獲とは扱わない。
47. **未来視**: プレイヤー手番に敵視点・深度2・300msのAI探索を別Workerで実行し、結果を予告表示する。合法手とAI評価は変更しない。
48. **必殺技カットイン**: 大技イベントを約900msの操作非阻害オーバーレイとしてキュー表示する。敵側の発動も表示する。
49. **超越レアのセーブ互換**: `throneCount`と`absorbed`は任意フィールドとし、欠落した旧セーブもそのまま動作する。

## 8. アーキテクチャ

Vite + TypeScript(strict)。ランタイム依存ゼロ。テストはVitest。

```

    types.ts       #   Piece / Board / GameState / Move / RunState 型定義

    abilities.ts   #   能力フックの実行エンジン
    pieces.ts      #   駒定義データ(通常8種+特殊70種+成り形+ボス3種)

    run.ts         #   ラン進行(ステージ・獲得駒・報酬抽選・編成)

  ai/
```

### 8.1 駒定義(データ+フック)

エンジン本体は個別の駒を知らない。新駒追加=`pieces.ts`に1エントリ追加で完結する。

```ts
interface PieceDef {
  id: string; name: string; kanji: string; rarity?: Rarity; // 通常駒はrarityなし
  moves: MovePattern[];        // step(1歩) / slide / jump / multiStep(獅子)
  promotesTo?: string;         // 成り先ID。なければ成れない
  isRoyal?: boolean;           // 王・太子・ボス駒
  hooks?: {
    blockCapture?:  (ctx) => boolean;  // 土竜・盾兵・軍神/覇王オーラ
    onCaptured?:    (ctx) => Effect[]; // 怨念・爆弾兵・妖狐・不死鳥
    onCapture?:     (ctx) => Effect[]; // 影の刺客の追加移動
    afterMove?:     (ctx) => Effect[]; // 磁将・石化の魔女(任意効果はUI/AIが選択)
    afterOpponentTurn?: (ctx) => Effect[]; // 九尾・覇王の回避ワープ
    active?:        ActiveAbility;     // 隠密・影武者・狙撃手・傀儡師(1ゲームN回)
  };
}
```

- 全フックは`Effect[]`(駒の消滅・移動・生成・状態付与)を返し、`game.ts`が一括適用する。乱数(不死鳥の復活先など)はシード付きRNGを使い、テストとリプレイを決定的にする。
- 石化などの状態はGameState側の`statusEffects`に持つ(駒定義は不変データ)。

### 8.2 AI

- ミニマックス+αβ枝刈り+反復深化。面ごとの深度と時間上限は§5。
- 評価関数: 駒割(通常駒は本家準拠の点、特殊駒はレアリティと動きの広さで加点)+王(ボス)の安全度+前進・中央支配の位置点+微小乱数(千日手ループ回避)。
- Web Worker内で実行。GameStateはシリアライズして受け渡す(構造化クローン可能なプレーンオブジェクトで設計)。

## 9. UI設計

- **タイトル**: 新規ラン(通常/初心者モード選択) / 続きから(セーブがある時) / 図鑑
- **編成画面**: 自陣3段+控え特殊駒リスト。クリックで入れ替え。駒にホバー/タップで動き図(9x9ミニ図)と能力説明を表示。「出陣」ボタンで対局へ
- **対局画面**: 盤面・両者の駒台・王手警告・面数/ボス表示・投了ボタン。操作は盤面タップで完結し、移動=琥珀、能力=紫、多段行動=水色、付随効果=緑で同時表示する。
- **段階式入力**: 成/不成、獅子・刺客・修羅の追撃、磁将・魔女、軍師連携はマス直上の44px以上のチップと次候補ハイライトで選ぶ。神罰は3×3プレビュー後の同一マス再タップで確定する。Esc・右クリック・範囲外タップでキャンセル可能。
- **必殺技演出**: 落雷・終焉・下剋上・十拳剣・刻停・波動球・天地返し・天下統一・後の先・蘇生・神罰は約900msのカットインを表示する。
- **未来視**: 自軍の未来視が盤上にいるプレイヤー手番は、敵の予測手を水色の始点・終点と「敵の狙い」表示で示す。
- **報酬画面**: カード3枚(レアリティ枠色: コモン=木色/アンコモン=銀/レア=金/神話=紫/天上=虹・白金/禁忌=血赤・黒/超越=プリズム・白金)+日本語レアリティ名+スキップ
- **図鑑**: レアリティ別一覧。未遭遇はシルエット。詳細に動き図と能力
- **敵駒確認**: プレイヤー手番中に敵駒をクリックすると、現在の盤面での移動範囲と能力対象を別色で盤上表示し、サイド欄へ敵向きの動き図と能力説明を表示する。
- **リザルト**: 勝利/敗北、到達面、今回のランの獲得駒一覧
- 駒は伝統的な五角形+漢字1〜2文字をCSSで描画。敵駒は180度回転。特殊駒はレアリティ色の縁取り。成り駒は赤字
- 表示言語は日本語のみ

## 10. テスト戦略

- `core/`は全てVitestでユニットテスト:
  - 通常駒8種+特殊駒70種+成り形+ボス3種の合法手生成(代表配置でスナップショット的に検証)
  - 各能力フックの裁定(§7のエッジケース全項目をテストケース化)
  - 成り(選択・強制)、持ち駒と打ち(二歩等)、勝敗判定(王取り・太子)、報酬抽選の確率境界
- AI健全性テスト: 王を1手で取れる局面で必ず取る/1手で取られる王を放置しない(深度2以上)
- 段階式ムーブセレクタはDOM非依存のVitestで分岐を検証し、UIは開発サーバで実プレイ確認する。
